# 005 — Private Research Agent

## Overview

在个人网站仓库内提供密码保护的私人技术调研工作台。固定入口为
`/p7x4m9q2-k6v8n3r5-t2w9c4h7/`，没有 `/lab/` 前缀。
本地实现已完成，真实 Qwen 调用和 LangSmith 摘要上传已获授权并验证。上线已获授权，目标为现有腾讯云服务器，
由网站私有路径代理到 Node 后端，保留 SQLite；已完成服务器部署及线上真实任务闭环。真实搜索仍不在范围内。
用户已取消博客 RAG，不索引博客、不增加向量数据库。

## User Stories

- 作为站长，我设置访问密码后才能查看工作台、历史报告及追踪。
- 我输入技术目标、约束和预算，查看助手的工具调用、补查依据和停止原因。
- 我可以取消任务、下载报告、复用任务配置、对比历史结果并留下人工反馈。
- 我可以离线模拟异常，检查预算、工具权限与追踪链路，无需真实 API 密钥。

## Functional Reqs

1. 仅监听 `127.0.0.1:4322`；根目录与其他路径返回 404，目标路径缺尾斜线时重定向。
2. 首次使用设置 6～256 字符密码，无默认密码；只保存加盐 scrypt 哈希。
   2026-10-22 按用户要求允许六字符本地密码；具体密码不写入代码或文档。
3. 服务端保护任务、报告、事件、历史、预算和追踪接口；页面隐藏不能替代接口鉴权。
4. 会话空闲 30 分钟或创建后 8 小时过期；退出即失效。登录失败 5 次后限制 15 分钟。
5. 决策循环使用 `search`、`read_page`、`calculate`、`save_report`、`finish` 白名单。
   网页读取仅允许已观察到的模拟搜索结果，不执行网页指令或任意代码。
6. 正常、空搜索、网页失败、来源冲突、恶意指令、网页超时、循环、非法动作、追踪失败共 9 种可选场景。
7. 12 轮决策、6 次搜索、8 页资料、30 秒任务时长；支持取消与部分报告。
8. 单次模拟预算 0.01～2 元；模拟日/月预算 10/100 元；北京时间记账，预留与执行费用持久化，单任务并发。
9. LangSmith 官方 SDK 默认生成离线父子追踪及请求数据；云端适配器需配置和独立显式启动参数。
10. 历史、报告、追踪、人工反馈持久化到本地 SQLite；重启中断任务并释放未用预留。
11. 所有报告和价格显著标为合成响应；无证据时不伪造引用，冲突时不作确定建议。
12. 百炼按用户配置使用北京 `qwen3.8-flash` 与通用 `https://dashscope.aliyuncs.com/compatible-mode/v1` 地址；核价后方可启用。
    原北京业务空间地址兼容；按精确模型名匹配已核定报价，未知模型拒绝真实模式，不套用其他模型的单价。
    密钥由用户在被忽略的本地文件自行填写。
    配置选择 qwen/cloud 后仍需各自显式启动参数，单独填写密钥或环境自动追踪变量不能授权网络调用。
13. 首次真实模型验证累计预算最多 5 元，SQLite 持久化预扣，不按日/月/重启重置，不自动退款或重试。
    模型请求前检查单任务和累计预算；usage 缺失保留预扣，超出 Token 边界锁定后续调用。
    Flash 使用完整输出限制 1200 Token，预留官方 10 Token 误差；每次预扣保存报价快照，原账本不重算或清零。
14. 真实模型启用后搜索/网页仍为合成工具，报告由模型生成并显著标注未联网调研；真实搜索不在此次接入范围。
15. LangSmith 云端仅发运行结构、计数、时间、状态和 usage 摘要，正文留在本地；累计最多 20 条试验 trace，不补传历史。
16. `save_report` 产生非空有效报告后立即由服务端结束，不再请求模型执行 `finish`；无效报告仍失败。
17. 生产服务仍只监听回环地址，由 HTTPS 代理访问；必须预置密码和原始累计账本，禁用线上初始化密码。
    `AGENT_PUBLIC_ORIGIN` 与可信代理头严格匹配，Cookie 增加 Secure。原账本预扣不得低于迁移时的下限。

## Non-Functional Reqs

- Node.js >=22.22.0；保留 Astro 静态构建，不将私有 HTML、脚本或路由加入公开输出。
- 登录、任务及追踪使用 no-store、noindex、同源校验、Host 校验、HttpOnly/SameSite Cookie 和 CSP。
- 本地 HTTP 不设置 Secure Cookie；生产 HTTPS 使用 Secure，仍需在线浏览器验收。
- 密钥留空由用户自行填写；只加载服务专用 `.env.local`，不提交、不打印、不返回密钥。
  默认运行及本次验证不得调用模型或上传追踪；环境变量单独不能切换为真实模式。
- 确认通过的信息通过 DOM 文本节点呈现；不执行模型返回的 HTML。
- 数据目录有进程锁，拒绝双进程同时使用同一数据库；不覆盖已有任务和测试证据。
- 电脑上的同权限进程仍可访问本地文件；本版本不承诺抵御已控制本机的程序。

## Data Model

SQLite 位于 `.tmp/research-agent/agent.sqlite`，处于 Git 忽略目录：

| 表 | 内容 |
| --- | --- |
| settings | 密码哈希 |
| sessions | 会话令牌 SHA256、创建/活动时间 |
| attempts | 登录失败次数和窗口 |
| tasks | 目标、约束、状态、北京时间日期、模拟费用预留/已用、报告、统计 |
| events | 按任务排序的行动记录 |
| traces | LangSmith run 格式的本地追踪 |
| wire | SDK 序列化请求体，不记录鉴权头 |
| feedback | 每个任务的 0/1 人工评分及备注，仅本地 |
| model_calls | 首次模型验证请求的持久化保守预扣、报价快照、usage 估算与未知费用状态 |
| cloud_dispatch | 试验 trace 发送占用记录，限制重放与累计数量 |

## API

以下相对路径均位于私有入口下，POST 要求同源 Origin 和 JSON（无请求参数的退出/取消亦校验 Origin）：

| 方法 | 路径 | 访问 |
| --- | --- | --- |
| GET | `api/auth/status` | 公开，仅认证/首次设置状态 |
| POST | `api/auth/setup`、`api/auth/login` | 公开，同源、限速 |
| POST | `api/auth/logout` | 登录后 |
| GET | `api/status`、`api/tasks` | 登录后 |
| POST | `api/tasks` | 登录后，校验输入/并发/预算 |
| GET | `api/tasks/:id` | 登录后，任务与事件 |
| GET | `api/tasks/:id/report`、`api/tasks/:id/trace` | 登录后 |
| POST | `api/tasks/:id/cancel`、`api/tasks/:id/feedback` | 登录后 |
