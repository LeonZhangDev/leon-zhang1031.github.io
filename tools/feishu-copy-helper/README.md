# 飞书图文复制插件

选中飞书文档里的内容，按 Ctrl+C，就能按需要复制为保留格式、纯文本或 Markdown。支持 Chrome 和 Edge，由 [LeonZhangDev](https://github.com/LeonZhangDev) 维护。

当前版本：2.3.0。产品介绍与下载入口位于 [个人网站的项目页](https://leonzk.cn/projects/)。

## 能做什么

| 模式 | 适合的用途 | 复制内容 |
| --- | --- | --- |
| 保留格式（默认） | 粘贴到 Word、飞书等富文本编辑器 | 纯文本和带常用样式的 HTML |
| 纯文本 | 记事本、搜索框、聊天输入框 | 选区原文，不主动清洗字符 |
| Markdown | 笔记、技术文档、代码仓库 | 标题、粗体、斜体、链接、列表、引用、代码块和普通表格 |

保留格式时，会从原页面读取字体、字号、颜色、高亮和对齐等样式，再写入复制内容。局部选择只复制选中的部分；输入框和文本框始终复制选中的原文。

图片保留引用地址，不会自动下载或内嵌。图片能否在其他应用中显示，仍取决于图片权限和目标应用。合并表格、复杂布局、飞书专用组件以及不同应用之间的排版差异，暂不承诺完整还原。

## 安装和更新

1. 下载发布包并解压，保留解压后的文件夹。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的文件夹。
5. 回到飞书文档并刷新页面。

更新已有安装时，先在扩展管理页点击本扩展的“重新加载”，再刷新已经打开的文档。扩展详情中的版本应为 **2.3.0**。

支持 `feishu.cn`、`larksuite.com` 及其子域名。

## 使用方法

打开扩展弹窗，在“默认复制模式”中选择保留格式、纯文本或 Markdown。设置保存在浏览器本地，切换后会同步到其他已打开的文档，刷新页面后也会保留。

- 选中内容，按 Ctrl+C；macOS 使用 Cmd+C。
- 选中内容后右键，可以临时选择另一种复制模式，不改变默认设置。即使选区没有图片，也能复制为 Markdown。
- 双击普通文字，会选择所在元素的内容，并使用默认模式复制；输入框和可编辑区域保留浏览器原本的双击行为。
- 原有“复制清洁版本”和“超级清洁版本”仍在右键菜单中。它们会改变字符，需要保留原文时请选择纯文本模式。

弹窗显示“当前页面已连接”时，表示页面脚本已回应、版本匹配并完成初始化。它不代表已取得文档管理权限，也不保证目标应用能保留所有格式。

## 遇到问题时

**显示“未连接到页面脚本”或“旧版脚本”**：重新加载扩展，刷新文档，再点“重新检测”。仅打开一个飞书网址，并不代表插件已经在页面上运行。

**粘贴后没有颜色或排版**：确认选择的是保留格式模式，并粘贴到支持富文本的编辑器中。记事本只接收纯文本，无法用来验收格式。

**图片没有显示**：图片引用可能需要登录或原文档权限。本版本没有增加图片下载或跨域访问权限。

**复制失败**：格式准备失败时会保留纯文本；主动复制的所有方案都失败时，会显示原文供手动复制，不会提示成功。快捷键使用浏览器真实复制事件，不依赖异步剪贴板权限。

## 本地数据与权限

新增的 `storage` 权限只用于保存复制模式。保留原有的 `activeTab` 权限，用于弹窗检查当前页面并与页面脚本通信。

复制内容在本地处理，不存储复制历史，不接入 AI 服务，也不上传文档内容。图片引用粘贴到其他应用后，该应用可能会请求原图片地址。

## 开发与测试

项目没有运行时依赖。核心文件如下：

- `copy-formats.js`：从真实选区读取样式，生成 HTML 和 Markdown。
- `content.js`：处理快捷键、复制事件、右键菜单和页面状态。
- `popup.html`、`popup.js`：切换模式、保存设置、检测页面连接。
- `manifest.json`：扩展配置。

无需安装依赖的逻辑测试和语法检查：

```powershell
node --test tests/copy-shortcut.test.cjs tests/popup-status.test.cjs
node --check copy-formats.js
node --check content.js
node --check popup.js
```

在已安装 Playwright 和 Chromium 的环境中运行浏览器测试：

```powershell
node tests/copy-shortcut-browser.cjs
node tests/copy-modes-browser.cjs
```

也可以通过 Playwright MCP 调用两个脚本导出的函数。使用已有 Playwright 安装时，可用 `PLAYWRIGHT_MODULE` 环境变量指定模块路径。

测试加载真实扩展，使用本地响应模拟飞书页面，不请求真实文档。浏览器检查覆盖实际 Ctrl+C/Ctrl+V、早期页面拦截、异步剪贴板禁用、常用格式、三种模式、跨标签页设置同步和真实消息握手。工具栏点击带来的 activeTab 网址授权在标签页形式的弹窗测试中由测试夹具补齐。

2026-10-21：2.3.0 已通过 18 项逻辑测试、17 项快捷键浏览器检查和 33 项格式及模式浏览器检查。Word、Notion 与真实飞书文档中的新版格式粘贴仍需分别验收。

2026-10-20：2.2 已通过 9 项逻辑测试和 16 项浏览器检查；用户在实际 Edge 飞书文档中手动完成 Ctrl+C → 记事本 Ctrl+V 验收，确认文字可以粘贴。该结论仅对应当时的纯文本场景。

打包时运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package-extension.ps1
```

发布包只包含扩展运行所需文件和本说明。测试、浏览器会话、依赖、日志、本地配置和凭据不进入安装包；这些本地文件也已加入 `.gitignore`。

## 更新记录

### 2.3.0

- 增加保留格式、纯文本、Markdown 三种默认模式，并在本地保存选择。
- 从原页面读取样式，保留常用格式；三种模式在右键菜单中始终可用。

### 2.0 / 1.0

原有版本提供文本选择、快捷键、右键菜单、双击复制、清洁文本、图文复制和 Markdown 转换。
