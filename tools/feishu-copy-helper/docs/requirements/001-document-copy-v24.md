# v2.4 文档格式复制与网页增强

## Overview

优化飞书格式复制，支持腾讯文字文档和用户按站点开启的网页增强，保留真实 copy 事件写入和状态检测。

## User Stories

- 选中文字后按 Ctrl+C，能粘贴正文及常用格式，段落不出现额外空行。
- 复制为原文或 Markdown，清楚知道图片和复杂格式是否处理成功。
- 普通网页由用户决定是否增强，并可记住本站或恢复原行为。

## Functional Reqs

1. 提供保留格式、纯文本、Markdown，按网站保存模式并同步已打开标签页。
2. 飞书 / Lark 和腾讯 `/doc/`、`/aio/` 文字正文自动适配；表格应用、幻灯片、PDF 不纳入适配。
3. 保留标题、列表编号、常用样式、段落缩进、代码块和普通表格。合并表格在 Markdown 中使用 HTML。
4. 去掉飞书布局容器造成的重复段落，保留正文空段落、软换行和代码空行。
5. 按需准备可读取的选区图片，显示成功与失败数；选区改变不得粘贴旧图片缓存。
6. 通用网页默认关闭；用户启用选择、右键和复制增强，粘贴增强单独勾选。
7. 记住本站时申请网站权限并注册 document_start 脚本，取消时注销并移除可选权限。
8. 状态来自脚本真实回应，区分未连接、旧版、初始化、保存失败和格式降级。

## Non-Functional Reqs

无运行时依赖、无 AI 服务、无复制历史及文档上传。不改原文，不请求文档接口。图片请求遵守正常跨域和凭据规则。关闭时只撤销插件自身效果。

选区克隆最多访问 20,000 节点；图片最多 20 张、单张 5 MB、总量 20 MB、单张请求 5 秒，准备 25 秒后不再开始新请求。

## Data Model

`storage.local.siteSettings[origin]` 保存 `mode`、`enabled`、`paste`、`remember`，兼容旧 `copyMode`。选区和图片准备只保存在当前页面内存。

## UI/UX

弹窗显示平台、连接版本、选区字符数和告警，提供模式、页面开关、记住本站、粘贴开关、图片准备和重新检测。文档右键菜单支持临时模式。

## API

使用 Chrome 扩展 storage、tabs、scripting、permissions API。消息为 `FEISHU_COPY_GET_STATUS`、`FEISHU_COPY_SET_MODE`、`DOC_COPY_CONFIGURE`、`DOC_COPY_PREPARE`、`DOC_COPY_SYNC_SITES`。不新增远程服务。

## Testing

逻辑测试、扩展浏览器夹具和真实文档分别记录。覆盖真实复制粘贴、局部选区、隐藏选区输入框、额外空段落、代码空行、表格、图片失败、缓存过期和站点开关。原生权限提示和本机编辑器粘贴需人工验收。

## Open Questions

Word、WPS、Notion 需要分别验证。腾讯不同文字编辑器实现需持续补充样本；公式与绘图使用提示和原应用导出。
